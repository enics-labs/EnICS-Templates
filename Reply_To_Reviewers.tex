\section{Response Letter Overview}\label{sec:overview}
The response letter uses the macros in \texttt{packages/reply\_macros.tex}, which is loaded by the journal templates. This file is appended to the manuscript with \textbackslash subfile\{Reply\_To\_Reviewers\} when \textbackslash replytoreviewerstrue is set in \texttt{main.tex}.

\subsection{Commands}
\begin{enumerate}
    \item \textbackslash editorsection: It generates the Editor block/section
    \item \textbackslash reviewersection: It generates a Reviewer block/section
    \item \textbackslash replySingle\{\#1\}: This command receives one input (\#1). This input is the reply to the reviewer. By default the answer is written in blue.
    \item \textbackslash replyFull\{\#1\}\{\#2\}: This command receives two inputs (\#1 and \#2). The former input is the reply to the reviewer, while the latter is the changes that we did to the manuscript. By default the answers are written in blue.
\end{enumerate}


\subsection{Use of Copy-Paste commands}
The \texttt{clipboard} package allows to ``copy'' and ``paste'' pieces of text from one document to another.
\textbf{It is suggested to use the ``copy'' command within the main manuscript and ``paste'' such a text in the changes block of the reply letter.}
In this way, it will save time and avoid possible human errors.
A brief description of the Copy-Paste commands follows:
\begin{itemize}
    \item \textbackslash Copy\{\#1\}\{\#2\}: It receives two inputs (\#1 and \#2). The former input is the name of the copied text. The latter is the text we want to copy.
    \item \textbackslash Paste\{\#1\}: It receives one input (\#1). It is the name of the text we want to paste. The name has to match the name used with the ``Copy'' command.
\end{itemize}

\subsection{Automatic generation of the reply file}
To ease some work, \href{https://github.com/EstebanJGC/Latex_Templates_Macros.git}{\red{here}} you can find a python script (named \textit{generateA2R.py}) that partially generates the reply file for $n$ reviewers, each one with a given number of concerns. Or just ask Claude to ``add a reply to reviewers'' and paste the review comments.

\subsection{Use of highlighting}
It is common to highlight changes in \blue{blue text}. What you should do is add the \textbackslash Copy command before the text and then add your \textbackslash blue command inside it. Then you can just use \textbackslash Paste in your reply document and the copied text will be blue.

You can use the ``\textbackslash hl\{\}'' to highlight some text.
It may be problematic if you highlight a text that presents some commands within it. To address this, it is suggested to close the command between ``\{\}'' or ``\textbackslash mbox\{\}''
\end{guidance}
